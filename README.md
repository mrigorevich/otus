# otus

Описание домашнего задания:<br><br>
Написать скрипт для CRON, который раз в час формирует отчёт и отправляет его на заданную почту.<br>
Отчёт должен содержать:<br>
IP-адреса с наибольшим числом запросов (с момента последнего запуска);<br>
Запрашиваемые URL с наибольшим числом запросов (с момента последнего запуска);<br>
Ошибки веб-сервера/приложения (с момента последнего запуска);<br>
HTTP-коды ответов с указанием их количества (с момента последнего запуска).<br><br>

Скрипт должен предотвращать одновременный запуск нескольких копий, до его завершения.<br><br>
В письме должен быть прописан обрабатываемый временной диапазон.<br><br>
